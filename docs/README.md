# Актуальные документы ForestProof

Для сдачи и защиты источниками истины являются:

1. `06-kejs-pereorientaciya.md` — требования, формулы и пользовательский сценарий.
2. `10-research-report.md` — исследовательский отчёт по условиям кейса.
3. `09-pitch-10-slajdov.md` — сценарий презентации.
4. корневой `README.md` — запуск, воспроизведение и архитектура.
5. `data/provenance_manifest.json` — машинный манифест происхождения опубликованных результатов.

Документы `00`–`05` описывают раннюю концепцию до получения окончательной постановки. Они сохранены только как история проектирования и не задают поведение сдаваемого решения. При расхождении всегда применяются документы из списка выше и официальная постановка организатора.
