# ForestProof · фронтенд

Vite + React + TypeScript. Без UI-кита: вёрстка на обычном CSS с токенами.

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

```bash
npm run build     # сборка в dist/
npm run preview   # посмотреть собранное
npx tsc --noEmit  # проверка типов
```

## Структура

```
src/
  styles/
    tokens.css        цвета, радиусы, сетка, типографика — всё отсюда
    base.css          сброс, шрифт, контейнер, брейкпоинты
  components/
    ui.tsx            Button, StatPill, Tag, InfoCard
    ui.css
  pages/
    Welcome/          приветственный экран (FR-01)
  App.tsx             роутинг: / и шесть разделов /app/*
public/images/        картинки из макета
```

## Правила

**Цвета и размеры только из `tokens.css`.** В компонентах хардкода быть не должно: дизайн-система одна на всё приложение, и менять её надо в одном месте.

**Сетка.** Макет нарисован на 1920 с полями по 100, контент 1720. Это зашито в `--canvas`, `--gutter`, `--content`.

**Шрифт.** В макете PP Neue Montreal — шрифт коммерческий, в репозитории его нет. Стек в `--font-sans` начинается с него: если появятся файлы лицензии, положить их в `public/fonts`, раскомментировать `@font-face` в `base.css` — и он подхватится сам. Пока подставляется Onest с Google Fonts: свободный гротеск с кириллицей, близкий по рисунку.

**Адаптив.** Ниже 1440 обложка из абсолютной раскладки превращается в обычный поток — на узком экране абсолютные координаты макета рассыпаются.
