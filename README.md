# ForestProof · Верификация климатических проектов по открытым спутниковым данным

Сервис независимой валидации и сверки углеродных проектов и лесных участков по открытым спутниковым продуктам (ESA CCI Biomass, Hansen Global Forest Change, MODIS Burned Area, Sentinel-2).

---

## 1. Локальный кэш спутниковых данных (data/cache/)

В соответствии с требованием регламента:
> *«Сохранённые исходные данные должны позволять повторить анализ при недоступности источника.»*

Скрипт tools/fetch.py обеспечивает автоматическое получение, валидацию и локальное кэширование необходимых растров.

### Быстрая проверка доступности источников без скачивания (--dry-run):
`bash
python tools/fetch.py --bbox 32.8 54.7 43.4 59.6 --years 2019 2024 --cover --dry-run
`
Скрипт отправляет легковесные HEAD-запросы и выводит статус доступности тайлов на серверах CEDA и Google Storage.

### Прогрев кэша одной командой (все 4 участка кейса, 2019–2024):
`bash
python tools/fetch.py --bbox 32.8 54.7 43.4 59.6 --years 2019 2020 2021 2022 2023 2024 --cover
`
Эта команда загружает тайлы N60E030 и N60E040 (Тверь, Вологда, Мордовия) и слои Hansen GFC в data/cache/.

### Структура кэша:
`
data/cache/
  cci-biomass/
    N60E030_ESACCI-BIOMASS-L4-AGB-MERGED-100m-2019-fv7.0.tif
    N60E030_ESACCI-BIOMASS-L4-AGB-MERGED-100m-2019-fv7.0.tif.json
    ...
  hansen-gfc/
    Hansen_GFC-2024-v1.12_lossyear_60N_030E.tif
    Hansen_GFC-2024-v1.12_lossyear_60N_030E.tif.json
    ...
`
Рядом с каждым скачанным файлом сохраняется .json с происхождением: URL, версия продукта, дата получения, точный размер в байтах и контрольная сумма **SHA-256**.

Каталог data/cache/ добавлен в .gitignore, чтобы тяжёлые растры не попадали в Git-репозиторий.

### Автономная работа при отключённой сети (--offline):
`bash
python tools/fetch.py --bbox 32.91 56.59 32.974 56.63 --years 2019 2024 --offline
`
При отсутствии сети или указании флага --offline система штатно переключается на использование локального кэша.

## 2. Запуск веб-приложения

`bash
cd app
npm install
npm run dev
`

Интерфейс откроется по адресу http://localhost:5173/.
