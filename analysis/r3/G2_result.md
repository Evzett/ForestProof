# Р3 G2 — результат расчёта

Технический отчёт для команды. Период проверки: **2019–2024**.

## Реализация и входные данные

`forestproof_core/case_calculation.py` выполняет чистый расчёт запаса, изменения, неопределённости, базовой линии и потенциальных единиц. `tools/extract_case_data.py` читает локальный набор и передаёт данные в ядро; проверки находятся в `tests/test_case_calculation.py`.

Используются контуры из `data/areas.geojson`, метаданные участков из `data/areas.csv`, годовые двухканальные растры `CCI_Biomass_*.tif` (AGB и AGB_SD), готовые годовые значения из `data/methodology/baseline.csv` и коэффициенты из `data/methodology/parameters.csv`. Связь выполняется по `aoi_id` и `baseline_id`. Каталог `data/` локальный и игнорируется Git. `rho_s = 0,5`, `rho_t = 0,7` и `k = 1,645` остаются настраиваемыми допущениями кейса: в `parameters.csv` их нет.

Перенесены формулы `c = AGB × CF_AGB`, `C = Σ(площадь пересечения пикселя × c)`, `E_proj = −ΔC × 44/12`, `E_base = −A × (c_base(t₁) − c_base(t₀)) × 44/12` и расчёт неопределённости по AGB_SD с пространственной и временной корреляцией. Площадь пикселя определяется геометрически; частичное пересечение с контуром учитывается. Для единиц: `R = E_base − E_proj − LK`, `UNC = min(1, max(0, H/R − 0,10))`, `R_adj = R × (1 − UNC)`, `Q = floor(R_adj × (1 − BUF))` при `R > 0` и `H/R < 1`. При `R ≤ 0` отношение `H/R` не вычисляется, `Q = 0`; при нехватке данных результат недоступен.

## Ограничение интерпретации

Это сценарный расчёт **по условиям кейса, а не сертифицированные углеродные единицы**. Он охватывает учитываемый пул надземной биомассы и заданные допущения по неопределённости и утечке; результат не подтверждает дополнительность проекта или выпуск единиц.
